Why Lakona

The freedom to build your game

🖥️

Start with a complete workspace

Hub or Tool creates the shared contracts, server host, hotfix project, and Unity or Godot client together.

🧩

Share C# contracts

Client and server compile the same RPC interfaces, DTOs, callbacks, and protocol types.

🔥

Reload behavior, keep state

Rebuild replaceable C# game behavior while long-lived player, room, and match state stays alive.

🗄️

Your game, your database

Integrate PostgreSQL, MySQL, MongoDB, or another database with your own .NET clients and data access layer. Keep your schema, queries, and familiar tools. Lakona imposes no database or ORM.

🚀

Start small and grow deliberately

Run a complete game server locally, then add sessions, reliable push, routing, and cluster deployment as your game grows.
